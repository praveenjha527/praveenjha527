# Praveen Kumar Jha

**I build open infrastructure that lets people, businesses and AI agents find each other, trust each other and exchange value, without a platform in the middle.**

Lead Architect at [NFH](https://nfh.global), based in Bangalore. My work runs from protocol design through to production: the specifications, the services that implement them, and the agent systems that now help build and operate them.

## What I'm building

- **Trust and discovery.** [Beckn](https://becknprotocol.io) and its ONIX adapter for open commerce, and [DeDi](https://dedi.global), a decentralised directory that lets any participant be looked up and verified.
- **Programmable value.** [Finternet](https://finternetlab.io) and UNITS, a ledger and tokenisation platform, and [Vouch](https://vouch.finance), purpose-bound vouchers for nutrition, education, farm inputs and AI compute.
- **Software that improves itself.** Multi-agent engineering systems that listen to production, turn signals into tested changes, and ship them through gates a person controls.

## Selected public work

- [ion-programmable-constructs](https://github.com/praveenjha527/ion-programmable-constructs): a working demo of composite settlement patterns for the Indonesia Open Network.
- [finternet-hackathon-api-suite](https://github.com/praveenjha527/finternet-hackathon-api-suite): the API suite used in Finternet hackathons.
